## YYYY-MM-DD - Axios Error Payloads Leak Passwords
**Vulnerability:** The application logs raw Axios errors (e.g., `console.error(err)`) in catch blocks during authentication actions (login/register). When Axios throws an error for these requests, the raw error object contains the original request payload in `err.config.data`, which exposes the plaintext password (and other sensitive information) to the browser console.
**Learning:** Raw error objects from HTTP clients like Axios often contain sensitive request context that can be leaked to users via the browser console or logging systems. It's unsafe to blindly log `err` without inspecting its contents or explicitly handling the message.
**Prevention:** Avoid logging raw HTTP client errors directly in frontend applications. Use the ES2019 optional catch binding syntax (`catch { ... }`) to silence errors securely when they only serve to update local error state (e.g., `error.value = '...'`), or parse and sanitize the error explicitly before logging.
