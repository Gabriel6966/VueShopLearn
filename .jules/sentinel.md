## 2024-05-20 - Exposing Plaintext Passwords via Axios Error Logs
**Vulnerability:** Raw `console.error(err)` logging in the `login` and `registro` functions within `src/stores/Usuario.ts` exposed the entire Axios error object to the browser console. Because Axios error objects (`err`) contain the original request payload in `err.config.data`, this leaked sensitive information like plaintext passwords when authentication or registration requests failed.
**Learning:** In Vite frontend applications and specifically when using Axios, raw error objects should not be logged directly as they may leak sensitive request payloads. This vulnerability pattern is specific to how Axios constructs error objects and attaches the original request configuration.
**Prevention:** Catch errors silently or handle them securely without logging the full error object or its configuration (e.g., using ES2019 optional catch binding `catch { ... }` or extracting specific non-sensitive messages via `err instanceof Error ? err.message : String(err)`).
