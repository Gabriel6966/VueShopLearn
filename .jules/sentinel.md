## 2024-07-14 - Prevent Credential Leak in Axios Error Logs
**Vulnerability:** Raw Axios error objects containing sensitive request payloads (including plaintext passwords during login and registration) were being logged directly to the console via `console.error(err)`.
**Learning:** When using Axios, the raw error object (`err`) includes the original request configuration and payload under `err.config.data`. If this is logged to the console, it exposes sensitive user data to the browser. It existed because default error handling often just logs the full error for debugging without considering the contents of the request.
**Prevention:** Avoid logging raw Axios errors directly, especially in authentication-related actions. Either catch the error silently if updating local error state is sufficient, or safely extract and log only non-sensitive parts of the error (e.g., `err.message` or `err.response.status`). Add an inline comment when intentionally omitting error logs to prevent future regressions.
