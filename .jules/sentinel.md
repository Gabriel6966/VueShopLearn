## 2025-07-21 - Fix Sensitive Information Leakage in Console
**Vulnerability:** Raw Axios errors were being logged to the console using `console.error(err)` in the authentication store (`src/stores/Usuario.ts`). This is problematic because Axios error objects often contain the original request payload in `err.config.data`, which can leak sensitive user information like plaintext passwords during login and registration attempts.
**Learning:** During failure handling for requests carrying sensitive credentials, it's easy to accidentally expose those credentials to the client console if the entire raw error object is logged for debugging purposes. This is especially true for XHR/fetch wrappers like Axios that attach the full request config to error responses.
**Prevention:** Avoid logging raw HTTP error objects directly, particularly in authentication flows. Catch errors silently, handle them securely by displaying generic user-facing error messages (e.g. updating local error state), and if logging is necessary, selectively log only safe properties like `err.message` or `err.response.status`, completely excluding the request configuration and payload.
