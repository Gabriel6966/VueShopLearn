## YYYY-MM-DD - [Axios Error Object Credential Leakage]
**Vulnerability:** Raw Axios error objects (`err`) were being logged directly to the browser console (`console.error(err)`) in authentication functions (`login`, `registro`). Because Axios includes the original request payload in `err.config.data`, sensitive information like plaintext passwords sent during login/registration could be leaked in the developer console.
**Learning:** In Vite/Vue frontend apps using Axios, standard `catch (err) { console.error(err) }` patterns are dangerous for endpoints handling sensitive data. The raw error object contains the complete request configuration, which bypasses frontend memory protections when logged.
**Prevention:** Avoid logging raw Axios errors directly, especially in functions handling authentication or PII. Use ES2019 optional catch binding (`catch { ... }`) to silence the error silently or extract only non-sensitive parts of the error (e.g., `err.message` or `err.response.status`) if logging is necessary.
