## YYYY-MM-DD - [Preventing Credential Leaks in Axios Error Logs]
**Vulnerability:** Raw console logging of Axios errors during login and registration (`console.error(err)`) inadvertently leaks the full request payload (`err.config.data`), which contains plaintext user passwords, to the browser console.
**Learning:** Axios error objects encapsulate the original request configuration, including sensitive data sent in POST bodies or GET parameters. Logging these raw objects in frontend applications exposes this sensitive data to anyone who opens the browser developer tools, which is a critical security risk.
**Prevention:** Catch errors silently using ES2019 optional catch binding (`catch { ... }`) when handling sensitive form submissions. Avoid logging raw error objects, and instead handle errors securely by updating local error state to notify users without leaking internal details. Add inline comments to explain why errors are caught silently to prevent future regressions.
