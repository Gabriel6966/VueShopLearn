## 2024-06-21 - Axios Error Object Credential Leakage
**Vulnerability:** Raw Axios error objects (`err`) were being logged directly to the browser console via `console.error(err)` in the authentication store (`src/stores/Usuario.ts`).
**Learning:** In Axios, when a request fails, the resulting error object contains the original request configuration in `err.config.data`. If the request contained sensitive information like plaintext passwords (such as in login or registration endpoints), logging the error object inadvertently leaks these credentials to the client's browser console, which could be exploited by malicious extensions or cross-site scripting (XSS).
**Prevention:** Never log raw Axios error objects directly. Catch errors silently using ES2019 optional catch binding (`catch { ... }`) or explicitly extract and log only safe properties (e.g., `err.message` or generic error codes). Redirect to generic error handling routines or update local error state to avoid exposing the internal request payload.
